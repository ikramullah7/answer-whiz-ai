# AnswerWhizAI

AnswerWhizAI is a locally branded RAG application based on RAGFlow v1.0.0-rc2. The React frontend is built from this repository; the Go backend currently runs from the published native ARM64 image `infiniflow/ragflow:v1.0.0-rc2`.

See [LOCAL_SETUP.md](LOCAL_SETUP.md) for the local Colima deployment and safeguards, [web/BRANDING.md](web/BRANDING.md) for frontend packaging, and [README.upstream.md](README.upstream.md) for the upstream project documentation.
