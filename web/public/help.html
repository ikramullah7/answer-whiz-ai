AnswerWhizAI Help

Get started

  1. Create a regular account on the login page. System administrator accounts are separate from workspace accounts.
  2. Open Settings → Model providers to configure your provider, then select default chat and embedding models.
  3. Create a dataset, select an embedding model, and upload your documents with parsing enabled.
  4. Wait for parsing to succeed, then use Retrieval testing to inspect the source chunks returned for a question.
  5. Create a chat assistant, connect your dataset, and verify answers against their source citations.

Improve answer quality

Inspect retrieved chunks before changing similarity thresholds, chunking, or reranking. Test both questions answered by your documents and questions they cannot answer. A citation does not guarantee every claim is correct.

Parsing and models

Parsing duration depends on document size and layout. Additional extraction, graph, and summarization features can consume more time and model tokens. Check the document task details and dataset logs when a job fails.

Provider credentials are managed in Settings. Keep API keys private. External model providers may receive document content and questions when processing requests.
